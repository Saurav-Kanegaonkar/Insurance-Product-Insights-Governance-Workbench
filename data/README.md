# Data Sources

Synthetic source-style data for P&C insurance product insights, KPI dashboards, and data governance.

- `entities.csv`: 36 product portfolio records.
- `daily_metrics.csv`: 5,040 product portfolio-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
